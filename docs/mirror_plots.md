# Mirror Plots

This document explains how to read and interpret the mirror plots generated by MSpecViz.

---

## What Is a Mirror Plot?

A mirror plot displays two spectra **face-to-face**: the query spectrum on top (positive intensities) and the reference spectrum on the bottom (negative/mirrored intensities). Peaks that appear at the same m/z position in both halves are shared fragments — the more alignment you see, the more similar the spectra.

```
     1.0 ┤        ╷ b5          ╷ y7
         │   b3   │     y4      │
         │    │   │      │      │
     0.0 ├────┴───┴──────┴──────┴────────── m/z →
         │    │   │      │      │
         │   b3   │     y4      │
    -1.0 ┤        ╵ b5          ╵ y7
              Query (top) vs Reference (bottom)
```

---

## Anatomy of a Mirror Plot

### Peaks (Vertical Lines)

Each vertical line represents one peak in the spectrum. The height corresponds to intensity and the horizontal position corresponds to its m/z value.

**Colors indicate ion type**:

| Color | Ion Type |
|-------|----------|
| Blue (#0066CC) | b-ions (N-terminal fragments) |
| Red (#CC0000) | y-ions (C-terminal fragments) |
| Yellow (#FFCC00) | a-ions |
| Green (#00CC66) | c-ions |
| Orange (#CC6600) | x-ions |
| Purple (#6600CC) | z-ions |
| Magenta (#8B008B) | Precursor ions |
| Teal (#00CED1) | Immonium ions |
| Grey (#AAAAAA) | Unannotated peaks |

### Annotations (Text Labels)

Annotated peaks display their ion label above (query) or below (reference) the peak tip. Labels include:
- Ion type and number (e.g., `b3`, `y7`)
- Charge state for multiply-charged fragments (e.g., `y12++`)
- Neutral losses if enabled (e.g., `b5-H2O`)
- Precursor notation (e.g., `[M+2H]2+`)

### Labels (Top-Left Corners)

- **Upper label**: `Query: {filename}` — identifies the query spectrum source
- **Lower label**: `Ref: {filename}` — identifies the reference spectrum source

### Metrics Box (Top-Right Corner)

A semi-transparent box displays abbreviated comparison metrics:

```
R2m=0.85  R2b=0.72
Cos=0.92  Ent=0.88
Dice=0.76 Jacc=0.61
ShR=0.83
```

See [Spectrum Metrics](spectrum_metrics.md) for detailed explanations of each metric.

### Title

The plot title shows the peptide sequence and modifications:
- `LGGNEQVTR` — unmodified peptide
- `PEPTMIDEK [Oxidation@M5]` — peptide with modification

### Center Line

A thin black horizontal line at y=0 separates the query (above) and reference (below) halves.

### Axes

- **x-axis**: m/z (mass-to-charge ratio)
- **y-axis**: Intensity
  - Relative mode: 0 to 1.0 (top) and 0 to -1.0 (bottom), labeled as absolute values
  - Raw mode: Auto-scaled, labeled as absolute values

## Interpreting Mirror Plots

### Good Match

A good match shows:
- Many colored peaks (high annotation coverage in both spectra)
- Peaks at the same m/z in both halves ("mirrored" positions)
- Similar relative heights for corresponding peaks
- High metrics (R2m > 0.8, Cos > 0.9, Dice > 0.7)

### Poor Match

A poor match may show:
- Few shared peaks (peaks in one half but not the other)
- Very different intensity ratios for shared peaks
- Many grey (unannotated) peaks dominating
- Low metrics (R2m < 0.3, Cos < 0.5, Dice < 0.3)

### Common Patterns

| Visual Pattern | Likely Cause |
|---------------|-------------|
| All peaks match, similar heights | Excellent replication / correct identification |
| Peaks match in position but different heights | Same fragments, different collision energy or ion optics |
| Upper has peaks, lower is sparse | Query has better fragmentation than reference |
| Many grey peaks in one spectrum | Low signal, noisy spectrum, or incomplete fragmentation |
| Shifted peaks (close but not aligned) | Possible m/z calibration issue — try increasing tolerance |
| Completely different patterns | Wrong identification, different peptide, or chimeric spectrum |

## Single Spectrum Plots

When no reference is available for a query spectrum (and "Plot unpaired spectra" is enabled), MSpecViz generates a **single spectrum plot** instead of a mirror plot:

- Only the upper half — peaks go upward from 0
- Same color coding and annotation labels
- No comparison metrics
- Source filename shown in the top-left label
- y-axis: 0 to 1.0 (relative) or auto-scaled (raw)

These plots are useful for visualizing fragmentation patterns independently.

## Plot Style

MSpecViz generates **publication-ready** static plots:

| Property | Value |
|----------|-------|
| **Figure size** | 12 x 8 inches (configurable in `settings.json`) |
| **Resolution** | 300 DPI (configurable) |
| **Background** | White (clean, no grid lines) |
| **Spines** | Left and bottom only (no top/right borders) |
| **Peak width** | 1.5 pt, 80% opacity |
| **Annotation font** | 7 pt |
| **Title font** | 14 pt, bold |
| **Axis label font** | 12 pt, bold |

## Export Formats

### PNG (Default)

Raster format at 300 DPI. Good for:
- Presentations and reports
- Quick visual review
- Sharing via email or chat

### SVG (Optional)

Vector format. Good for:
- Publications (infinitely scalable)
- Editing in Adobe Illustrator or Inkscape
- High-quality printing

Both formats use a white background with tight bounding boxes.

---

## Filename Convention

Exported plot filenames follow this pattern:

**Mirror plots**:
```
{peptide}_{query_stem}_vs_{ref_stem}.png
```

Example: `LGGNEQVTR_Patient01_C3_vs_Synpep01_C3.png`

**Single spectrum plots**:
```
{peptide}_{source_stem}.png
```

Example: `LGGNEQVTR_Patient01_C3.png`

Filenames are sanitized: invalid characters are removed, and names are truncated to a reasonable length.

## Directory Structure

Plots are organized into subdirectories by peptide variant:

```
exports/MSpecViz_analysis_20260219_143000/
├── comparison_summary.csv
├── comparison_summary.xlsx
└── png/
    ├── LGGNEQVTR/
    │   ├── LGGNEQVTR_Patient01_vs_Synpep01.png
    │   ├── LGGNEQVTR_Patient01_vs_Synpep02.png
    │   └── LGGNEQVTR_Patient02_vs_Synpep01.png
    ├── GAGSSEPVTGLDAK/
    │   └── ...
    └── PEPTMIDEK_Oxidation_M5/
        └── ...
```

If SVG export is enabled, a parallel `svg/` directory mirrors the same structure.

## Customizing Plots

### Via `settings.json`

```json
{
  "export": {
    "dpi": 300,
    "figsize": [12, 8]
  },
  "ion_colors": {
    "b": "#0066CC",
    "y": "#CC0000"
  }
}
```

### Programmatically

The `create_mirror_plot()` function accepts parameters for customization:

```python
from src.mirror_plot import create_mirror_plot

fig = create_mirror_plot(
    upper_spectrum=query_df,
    lower_spectrum=ref_df,
    title="My Custom Title",
    upper_label="Experiment A",
    lower_label="Standard",
    figsize=(16, 10),
    dpi=600,
    annotation_fontsize=9,
    normalize=True,
)
fig.savefig("custom_plot.png", bbox_inches='tight', facecolor='white')
```
