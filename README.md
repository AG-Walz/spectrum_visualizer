# General purpose

This app can be used to visualize, compare and plot spectra generated by MHCquant. It is a streamlit app that can be run
on your local machine using a conda virtual environment.
## How to use
If this is the first time that you are running this pipeline, please look at the [read me](https://github.com/AG-Walz/README) in the home page. This would save time from both parties (yours and the bioinformaticians).
### First time setup
- [Download](https://docs.conda.io/en/latest/miniconda.html) and install miniconda for Windows
- Follow the installation instructions of this [video](https://www.youtube.com/watch?v=tXgPY4lc6fo)
- Once you downloaded and installed miniconda, open the Command Prompt
- Create a new conda environment using the following command:
```bash
  conda create -n spectrum_visualizer -c conda-forge -c anaconda git pandas adjusttext streamlit scikit-learn
```
### Running the app
```bash
  conda activate spectrum_visualizer
  # Navigate to the directory where you want to clone the repository
  cd \path\to\directory
  # Clone the repository in the current directory
  git clone https://github.com/AG-Walz/spectrum_visualizer
  # Navigate to the cloned repository
  cd spectrum_visualizer
  # Run the app
  streamlit run Welcome.py --server.maxUploadSize=1028 --server.maxMessageSize 1028
```

### Input files

The input files are files generated by the ion annotator module of MHCquant. The files that are needed are located in
`results/intermediate_results/ion_annotations` of the MHCquant output folder. For each sample the needed files are:
`sampleID_all_peaks.tsv` and `sampleID_matching_ions.tsv`

Put those files in the `data` directory of the spectrum visualizer.

---

### Output files

The output plots are located under the ``plots`` folder in the spectrum visualizer directory
